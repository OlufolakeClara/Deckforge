# DeckForge AI — Startup Pitch Deck Generator

Live Website: https://deckforgeai-olufolake.vercel.app/

An AI-powered tool that automatically generates an investor-ready startup pitch deck (covering problem, solution, market size, traction, and funding ask) in under 3 seconds using frontier large language models.

## 🛠️ Technical Features & Architecture
- **Instant Generation Pipeline:** Integrated with the Gemini Flash API to stream and structure investor-ready narrative structures instantly.
- **Dynamic Content Formatting:** Autogenerates standard venture capital frameworks including Problem Definition, Solution Mapping, TAM/SAM Market Sizing, and Traction matrices.
- **Export System:** Custom built editing interface allowing users to refine, format, and prepare decks for investor presentation.

## 🧰 Technical Stack
- **Frontend Framework:** React, Next.js
- **AI Core:** Gemini Flash API (Google AI SDK)
- **Deployment Infrastructure:** Vercel
